## О проекте

**Libra** — веб-приложение для управления физической библиотекой.

Система предназначена для автоматизации учёта книжного фонда, читателей, физических экземпляров книг, выдач, возвратов и бронирований.

В проекте предусмотрено разграничение доступа для двух ролей: **читатель** и **библиотекарь**.

Подробное описание архитектуры, функциональных возможностей и используемых технологий представлено в [Лабораторной работе №1](docs/ARCHITECTURE.md).
